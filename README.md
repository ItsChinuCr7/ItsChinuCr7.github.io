# ItsChinuCr7 Portfolio

React + Vite personal portfolio hosted on GitHub Pages.

## Recent navigation change
The previous expandable orbit menu has been removed. Six section destinations remain visible at all times. A small animated dog hops above the hovered, keyboard-focused, or active navigation link. Navigation remains accessible on desktop and mobile, and honors reduced-motion settings.

## Local development

```powershell
npm install
npm run dev
```

## Production check

```powershell
npm run build
npm run preview
```

The GitHub Pages deployment workflow is located at `.github/workflows/deploy.yml`. Preserve the existing `.git` directory when replacing local project files with this archive.
